# 🚗 DVLD - People Management System

## 📌 Overview

DVLD (Driving & Vehicle License Department) is a desktop application developed using .NET for managing people records and driving license services.
The system is designed with a clean multi-layer architecture to ensure scalability, maintainability, and separation of concerns.

---

## 🎯 Features

* 👤 Manage people records (Add / Edit / Delete / View)
* 🪪 Handle driving license services
* 🔍 Search and filter functionality
* 🗂 Organized data management
* 🧩 Multi-layer architecture (Presentation, Business, Data Access)
* 💾 Database integration

---

## 🏗️ Project Structure

```
DVLD-People-Management-System/
 ├── DVLD.sln
 ├── DVLD/                # Presentation Layer (UI)
 ├── DVLD_Business/       # Business Logic Layer
 ├── DVLD_DataAccess/     # Data Access Layer
```

---

## 🧱 Architecture

The project follows a **3-Tier Architecture**:

* **Presentation Layer**
  Handles user interface and user interactions.

* **Business Layer**
  Contains application logic and rules.

* **Data Access Layer**
  Responsible for database operations (CRUD).
